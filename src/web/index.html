表示

離席中に起きた変化を、既読にするまで表示します。
「マージできます」と出す条件
条件が残っていてもマージ操作が可能なら、確認欄に未達の条件を表示する。
プルリクエストの取得に使う gh を同時に動かす数。大きいほど一覧の更新が速く、PC と GitHub API への負荷が増える。変えた値は次に起動する gh から効く。
自動では、Windows Terminal、PowerShell 7、Windows PowerShell の順に、見つかったものを使う。選んだ端末が見つからないときは開かずに知らせる。
オンでは、既定ブランチへのマージを検出したとき、そのブランチをチェックアウトしているローカルの作業ツリーを fast-forward で更新する。追跡しているファイルに未コミットの変更がある作業ツリーは更新せず、セッションへ知らせる。
オンでは、アプリの一覧を 1 つのタスクの完了条件として取り込む。依頼ごとの題はモデルが登録する。オフでは、モデルが Agent Cockpit に直接登録したタスクだけを出す。Codex のセッションには取り込める一覧が無いので、この設定にかかわらず取り込まない。

セクションの並び順

種類別はこの順に並ぶ。プロダクト別は、セッションの中の 3 つがこの順に並び、「前回見てから」と「プルリクエスト」は、3 つのどれより前ならセッションの上、それ以外は下に出る。

    オンにすると、Claude Code デスクトップアプリのタスク一覧を 1 つのタスクの完了条件として取り込み、題はモデルが付けます。Codex のセッションでは取り込みません。
    オフにすると、従来どおり、モデルが Agent Cockpit に直接登録したタスクを表示します。
