Agent Cockpit でできること

Agent Cockpit は、Claude Code デスクトップアプリで動いているセッションの状態を 1 つの画面にまとめるダッシュボードです。このマニュアルでは、画面の見方と、判断事項への回答、PR のマージ、離席中の使い方を説明します。

できること

  • 複数のセッションの今やっていること、タスク、サブエージェントを一覧する
  • 許可待ちと判断待ちを、待ち時間の長い順に確かめる
  • 判断事項にダッシュボードから回答する
  • 席を外している間、質問の回答を待たせる時間を決める
  • PR のスタックを確かめ、条件がそろったものを画面からマージする
