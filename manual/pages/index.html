Agent Cockpit でできること

Agent Cockpit は、Claude Code デスクトップアプリで動いているセッションの状態を 1 つの画面にまとめるダッシュボードです。このマニュアルでは、使い始め方、画面の見方、判断事項への回答、PR のマージ、離席中の使い方、設定と運用を説明します。

できること

  • 複数のセッションの今やっていること、タスク、サブエージェントを一覧する
  • 許可待ちと判断待ちを、待ち時間の長い順に確かめる
  • 判断事項にダッシュボードから回答する
  • 席を外している間、質問の回答を待たせる時間を決める
  • PR のスタックを確かめ、条件がそろったものを画面からマージする
  • サブエージェントとクロスレビューを、Codex と Claude のどちらで行うかを選ぶ

目的から探す

  • 導入した後に、ダッシュボードを開きたい：ダッシュボードを開く
  • 画面のどこに何があるかを知りたい：画面の見方
  • タスクと完了条件、サブエージェントの動きを見たい：タスクと今やっていること
  • 許可待ちを確かめたい：許可待ち
  • 判断事項に回答したい：ダッシュボードから回答する
  • 席を外している間の質問を、ダッシュボードで受けたい：離席中
  • 席を外している間に、判断を返したい：席を外している間に判断を返す
  • PR をマージしたい：マージする
  • 積み上げた PR を、下から順にマージしたい：積み上げた PR を順にマージする
  • サブエージェントやクロスレビューの経路を切り替えたい：経路の設定
  • 配色や、待ち時間や、一覧の並びを変えたい：表示の設定
  • タスクトレイの使い方や通知を知りたい：タスクトレイ
  • 常駐サーバーを再起動したい、保存先を知りたい：常駐サーバーと保存されるもの
  • うまく動かない：困ったとき
