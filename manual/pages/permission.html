許可待ち

Claude Code が利用者への許可確認を通知したとき、あなたの判断が必要なこと の欄に、許可待ちのカードが出ます。 このページでは、カードの見方と、待ち時間の強調を説明します。 許可を出す操作はダッシュボードにありません。

許可はセッションを動かしているアプリで出す

許可待ちのカードが出たら、そのセッションを開いている Claude Code の画面で許可または拒否を選んでください。 ダッシュボードから許可を出すことはできません。 ダッシュボードは、許可待ちが起きていることと、待たせている時間を知らせる表示だけを受け持ちます。

どこで操作すればよいかは、カードの最下段の 1 行に書いてあります。 操作するアプリ(Claude Code または Codex)、プロダクトの名前、セッションの名前が出ます。

実行許可を確認中

Codex からツールの実行前の許可要求を受けたときは、今やっていること に 実行許可を確認中 と出ます。 自動判定やフックの処理中もあるため、この表示だけでは利用者の操作が必要とは限りません。 判断欄や許可待ちの件数には含めず、待ち時間が長くなっても判断待ちへ切り替えません。

Codex は、利用者が操作できる許可画面が出たことを Agent Cockpit から確認できないため、許可要求をこの状態で表示します。 Codex 自体に許可画面が出た場合は、Codex の元の画面で操作してください。

Claude Code の標準設定では、利用者への許可確認の通知を受けて 許可待ち を表示します。 実行前の許可要求を送る PermissionRequest フックを追加登録した環境では、Claude Code にも 実行許可を確認中 が出ます。

Claude Code で複数ツールのうち一部が完了し、操作がまだ必要か確認できなくなった場合も、実行許可を確認中 に戻ります。 このときは判断欄や許可待ちの件数から外します。 残るツールが一つになっても自動で許可待ちとはせず、新しい許可確認の通知を受けてからカードを表示します。

許可待ちのカード

許可待ちのカードは、セッションが許可を求める通知を出した時点で現れます。 許可を求めているのがメインセッションか、サブエージェントかは、見出しで分かります。

Claude Code のカードは、許可を待っていたツールが終わると消えます。 成功しても、失敗しても同じです。 メインセッションの許可待ちは、ターンが終わったときと、新しいプロンプトを送ったときにも消えます。

同じ作業者(メイン、または同じサブエージェント)が新しい許可待ちを出したときは、前のカードを置き換えます。 メインと、各サブエージェントは、別々に 1 件ずつ数えます。

許可を待っているツールの表示の詳細

実行前の許可要求が記録されていれば、そのツールを表示します。 Claude Code の通知だけを受けた場合は、同じ作業者の未完了ツールが一つだけなら、そのツールを表示します。 Agent ツールは、サブエージェントが終わるまで続くので、候補にしません。 該当するツールが見つからないときや複数あるときは、対象を断定せずツールの行を出しません。

セッションが開始、再開、クリアされたときは、メインの許可待ちを消します。

長く待たせているとき

待ち時間が設定の時間を超えると、カードの背景が赤みを帯び、待ち時間が太い赤の文字になります。 時間は、設定の 長く待たせているとみなす時間 (1〜120 分) で決めます(長く待たせているとみなす時間)。 既定は 15 分で、ちょうどその時間に達しただけでは強調しません。

待ち時間は 1 分ごとに更新します。 同じ強調は、止めて待っている判断事項にも付きます(経過時間と強調)。

許可待ちの数

許可待ちの数は、次の場所に出ます。

  • 画面上部の 許可待ち の札(件数の札)
  • プロダクトのカードの見出しの 許可待ち の札(プロダクトのカード)
  • ブラウザのタブの題の、先頭の括弧の数。許可待ちと、回答を送っていない止めて待っている判断事項の合計です

件数の札を押して許可待ちを隠すと、カードは一覧から消えます。 タブの題の数は、隠していても数えます。
